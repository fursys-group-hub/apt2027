# 공부방람회 혜택계산기 (원본)

일룸 견적서(PDF·엑셀·워드·캡처 이미지)를 올리면 올데이페스타(LG제휴 포함) · 공부방람회 프로모션(뉴트) · 모션컬렉션 중 받을 수 있는 혜택을 계산합니다.

- `index.html` : 원본 (Claude 아티팩트와 동일한 코드). 읽기 도구는 CDN(cdnjs·jsdelivr)에서 불러오고, 캡처 이미지는 Claude 판독 기능을 쓸 수 있는 환경에서는 Claude로, 그 밖에서는 브라우저 글자 인식으로 읽습니다.
- 공개 배포판 : 저장소 루트의 `공부방람회_혜택계산기.html` (읽기 도구를 `lib/benefit-calc/`에 포함해 CDN 없이 동작)

기준 자료: 26년 프로모션 대시보드(올데이페스타·LG제휴), 2027 신학기 프로모션 시트, 모션컬렉션 공지 시트, 스터디 아이템리스트(26.10.2), 일룸 공식몰. 2026-11-25 기준.
